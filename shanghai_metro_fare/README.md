# 上海地铁最短路径与票价查询

输入起点站和终点站，输出最短路径、里程，以及**调价前（现行）**与**调价后（听证方案一、方案二）**的票价。

背景：上海地铁 2026-08-19 公布 21 年来首次票价优化听证方案（2026-09-07 听证，两套方案并存，尚未实施），本工具同时计算现行票价与两套方案的票价。

## 用法

**网页版（推荐）**：双击 `index.html` 即可在浏览器中使用——站名自动补全、线路配色路径、少换乘/最短双路线、三套票价对比卡片，无需启动任何服务（数据已内嵌，可离线使用）。

**命令行版**：

```bash
python metro_fare.py <起点站> <终点站> [--plan all|current|plan1|plan2]
python metro_fare.py --selftest          # 用官方公布的示例票价自检
```

示例：

```
$ python metro_fare.py 人民广场 陆家嘴

路线：人民广场(2号线) → 南京东路(2号线) → 陆家嘴
  人民广场 → 陆家嘴（2号线，约 2.8 km）
总里程：约 2.8 km（3 站）

现行票价：3 元
方案一(3元起乘)：3 元
方案二(4元起乘)：4 元
```

- 站名支持模糊匹配：`人民广`、`浦东机场`（自动映射为 浦东1号2号航站楼）、`虹桥机场` 等；多个候选时提示交互选择
- 换乘站按站名自动合并（如 人民广场 = 1/2/8号线），换乘不计费
- **双路线展示**：票价按"全网最短路径里程"计价（官方规则），该路径可能为省里程而多换乘；工具同时给出**少换乘路线**（换乘最少、同换乘数取更短），两条路线票价相同
- 纯标准库实现，无第三方依赖；Python 3.10+

## 票价规则

**现行（2005 年机制）**：起步 3 元 / 6 km，此后每 10 km 加 1 元
→ 区间：(0,6] 3 元，(6,16] 4 元，(16,26] 5 元，…

**方案一（起乘价不变）**：起步 3 元 / 4 km，加价间距 4、4、4、7、7、7、10、10、10 km，67 km 以上每 15 km 加 1 元
→ 区间：(0,4] 3 元，(4,8] 4 元，(8,12] 5 元，(12,16] 6 元，(16,23] 7 元，(23,30] 8 元，(30,37] 9 元，(37,47] 10 元，(47,57] 11 元，(57,67] 12 元，此后每 15 km +1 元

**方案二（提高起乘价）**：起步 4 元 / 6 km，加价间距 6、8、8、10、10、12、12 km，72 km 以上每 14 km 加 1 元
→ 区间：(0,6] 4 元，(6,12] 5 元，(12,20] 6 元，(20,28] 7 元，(28,38] 8 元，(38,48] 9 元，(48,60] 10 元，(60,72] 11 元，此后每 14 km +1 元

票价按区间 `(起, 止]` 计算（恰在边界上按低一档）。三套规则均已通过官方公布示例自检：

| 示例线路 | 现行 | 方案一 | 方案二 |
|---|---|---|---|
| 人民广场 → 陆家嘴 | 3 元 | 3 元 | 4 元 |
| 虹桥火车站 → 南京东路 | 5 元 | 7 元 | 6 元 |
| 西岑 → 滴水湖（全网最高） | 15 元 | 16 元 | 15 元 |

## 数据与距离模型

- **数据源**：高德地图地铁页内嵌 JSON（`https://map.amap.com/service/subway?...&srhdata=3100_drw_shanghai.json`，抓取于 2026-08-19），含全部 19 条常规线路（1-18 号线 + 浦江线）415 个站点；`fetch_data.py` 可重新抓取
- **排除线路**：磁浮线、市域机场线、金山铁路（官方调价方案不含，也未计入网图）
- **距离**：相邻站点用 haversine 球面直线距离 × 1.03 近似轨道里程（系数经三个官方示例反推校准，亦与全网轨道/直线比 ≈ 831/766 km 相符）。Dijkstra 求最短路径即为计费里程（与官方"按最短路径里程计费"一致）
- **已知局限**：直线距离近似在里程边界附近可能与实际票价相差 1 元；虹桥2号航站楼为 2/10 号线虚拟换乘站，本工具按交通卡连续计费规则计算（单程票实际需出站重购）
- 高德坐标使用 GCJ-02 坐标系，全网一致，不影响距离计算

## 文件结构

```
shanghai_metro_fare/
├── index.html         # 网页版（自包含，双击即用，双击前请先确保为最新构建）
├── web_template.html  # 网页模板（含全部 UI 与 JS 逻辑，数据以占位符内嵌）
├── build_web.py       # 将 data/*.json 内嵌进模板，生成 index.html
├── metro_fare.py      # 主 CLI：建图 → 最短路径 → 三套票价
├── fetch_data.py      # 下载高德数据并生成 data/stations.json + edges.json
├── data/
│   ├── stations.json  # 站名 → 经纬度、所属线路
│   ├── edges.json     # 相邻站点边（直线距离 km）
│   └── raw/           # 原始数据缓存（高德 JSON + 上海地铁官网 pca.js）
└── README.md
```

网页版与 CLI 的图构建、最短路径、票价算法完全同构（JS 与 Python 实现已在 10 组站点对上交叉验证一致）。数据更新后重新构建网页：`python build_web.py`。
